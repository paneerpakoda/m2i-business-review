# Money2India Business review prototype

[Open the prototype](https://paneerpakoda.github.io/m2i-business-review/)

This repository contains only the compiled website for design review.
Application source and internal development documentation are stored separately.

Use **Prototype → Fill sample application** and OTP **123456** to try the journey.
The sample includes Maya Patel as a direct shareholder and an owner of the entity.
Upload dialogs include **Use sample document**. This is a simulation: no real account
is created, no OTP is sent, and no document is uploaded to a server. Refresh resets the sample.
